# The menu bar

Every command on LocalBooks' menu bar, menu by menu, and where it takes you. Most commands open a
screen that is also in the sidebar; the guide for that screen explains it step by step. Shortcuts
are shown for Windows and Linux; on a Mac, use ⌘ for Ctrl unless the row says otherwise. On Windows,
press **Alt** to reach the menus from the keyboard (for example **Alt+U** for Customers).

A command for a feature that is turned off in Preferences (estimates, sales orders) is greyed out.

## File

| Command | Shortcut | What it does |
|---|---|---|
| **New Company…** | | Starts a new company file with the setup assistant. See [Create a new company](getting-started.md#create-a-new-company). |
| **Open or Restore Company…** | Ctrl+Shift+O (⌘O on a Mac) | Opens a LocalBooks company file or backup, or a QuickBooks company file, backup or portable file to bring in. See [Open another company file](backups-and-company-files.md#open-another-company-file). |
| **Open Company Without Restoring Windows…** | Ctrl+Alt+O | Opens a company on a plain Home page, without the windows it had open. |
| **Open Previous Company** | | The company files you opened most recently. **No Recent Companies** shows when there are none. |
| **Close Company** | | Closes the books and shows the **No Company Open** screen. |
| **Back Up Company › Create Local Backup…** | | Opens File & Data Controls to back up now. See [Back up](backups-and-company-files.md#back-up). |
| **Utilities › Import / Convert…** | | Opens the Desktop Migration Wizard. See [Desktop Migration Wizard](desktop-migration.md). |
| **Utilities › Export › Lists to IIF Files…** | | Saves the chart of accounts, customers, vendors, items and classes as an IIF file. |
| **Utilities › Export › Addresses to Text File…** | | Saves every active customer's and vendor's address for a mail merge. See [Export lists and addresses](backups-and-company-files.md#export-lists-and-addresses). |
| **Utilities › Condense Data…** | | Opens File & Data Controls at Condense data. See [Condense data](backups-and-company-files.md#condense-data-archive-closed-years). |
| **Print Forms › Invoices…** | | Invoices waiting in Print later, to print as a batch. |
| **Print Forms › Sales Receipts…**, **Credit Memos…**, **Bill Payment Stubs…**, **Purchase Orders…** | | Prints that kind of form in a batch, for a date range. |
| **Print Forms › Checks…** | | Checks waiting to print; each takes its number as it prints. |
| **Print Forms › Statements…** | | Opens Customer Statements. See [Customer statements](customer-statements.md). |
| **Print Forms › Mailing Labels…** | | Customer or vendor addresses, 30 to a Letter sheet. |
| **Send Forms…** | | Forms marked Email later, ready to send. See [Email later and Send Forms](custom-forms.md#email-later-and-send-forms). |
| **Print… (Ctrl+P)** | Ctrl+P | Prints what is in front: the open form, a register's transactions for its dates, or the window. |

On a Mac, **File › Close Window** (⌘W) closes the window that is active inside LocalBooks.

## Edit

Besides Undo, Cut, Copy, Paste and Select All, the Edit menu acts on the form or list in front.

| Command | Shortcut | What it does |
|---|---|---|
| **Delete or Void Transaction (Ctrl+D)** | Ctrl+D | Voids the saved transaction open on the form (or clears a new one). |
| **Memorize Transaction (Ctrl+M)** | Ctrl+M | Keeps the form as a memorized transaction to enter again. See [Memorized and recurring transactions](memorized-transactions.md). |
| **Insert Line (Ctrl+Insert)**, **Delete Line (Ctrl+Delete)** | Ctrl+Insert, Ctrl+Delete | Adds a blank line above the one you are on, or removes it. |
| **Copy Line (Ctrl+Alt+Y)**, **Paste Line (Ctrl+Alt+V)** | Ctrl+Alt+Y, Ctrl+Alt+V | Copies a line and pastes it above the line you are on (Control+Option on a Mac). |
| **Go To Transfer (Ctrl+G)** | Ctrl+G | On a saved transfer, opens the other account's register at it. |
| **Duplicate Transaction (Ctrl+O)** | Ctrl+O (Control+O on a Mac) | Starts a new copy of the saved transaction, dated today. See [Duplicate a transaction](getting-started.md#duplicate-a-transaction). |
| **New in List**, **Edit in List**, **Delete from List** | | Adds, edits or deletes a row of the customer, vendor or item list on screen. Only a record that was never used can be deleted. |
| **Make Inactive / Active** | | Hides the selected record from new forms without losing its history, or brings it back. |
| **Show All (inactive too)** | | Shows inactive records in the list. |
| **Use Register** | Ctrl+R | Opens an account register. |
| **Find…** | Ctrl+F | Opens Find Transactions. See [Find a transaction](journal-entries-and-voids.md#find-a-transaction). |
| **Preferences…** | | Opens the Preferences Console. See [Preferences reference](preferences.md). |

## Window

| Command | What it does |
|---|---|
| **New Window** | Opens a second LocalBooks window on the same company (Ctrl+Shift+N). |
| **Close All** | Closes every window inside LocalBooks. |
| **Cascade**, **Tile Vertically**, **Tile Horizontally**, **Arrange Icons** | Arranges the windows inside LocalBooks, or lines up the minimized ones. |
| **Workspace › AutoSave**, **Manual**, **Save Workspace** | On a Mac: whether the windows you have open reopen with the company. See [Reopen your windows with the company](getting-started.md#reopen-your-windows-with-the-company-saved-desktop). |

The rest of the Window menu lists the windows open inside LocalBooks.
